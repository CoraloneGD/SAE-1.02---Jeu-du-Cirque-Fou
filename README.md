# SAÉ 1.02 - Jeu du Cirque Fou 🎪

Ce projet a été réalisé dans le cadre de la **SAÉ 1.02 (Comparaison d'approches algorithmiques)** au sein du BUT Informatique. 

Le "Jeu du Cirque Fou" est une simulation de gestion développée en **C**, dont l'objectif est d'optimiser les structures de données et les algorithmes de traitement pour garantir une expérience de jeu fluide.

## 📝 Présentation du projet

Le joueur incarne un directeur de cirque qui doit gérer ses ressources, ses artistes et ses spectacles. L'enjeu de cette SAÉ est principalement porté sur l'efficacité algorithmique.

### Objectifs techniques :
- **Algorithmique & Complexité :** Comparaison de différentes méthodes de tri et de recherche.
- **Gestion de la mémoire :** Utilisation rigoureuse des pointeurs et de l'allocation dynamique en C.
- **Modularité :** Découpage du code en fichiers sources (`.c`) et en-têtes (`.h`).
- **Fichiers :** Lecture et écriture des données de jeu (sauvegardes, statistiques).

## 🚀 Fonctionnalités

- [x] **Moteur de jeu :** Gestion des tours, des événements aléatoires et du budget.
- [x] **Système de Tri :** Implémentation de tris (bulle, insertion ou rapide) pour classer les scores ou les artistes.
- [x] **Persistance :** Sauvegarde et chargement de la progression via des fichiers `.txt` ou binaires.
- [x] **Interface Console :** Menu interactif et affichage des statistiques de fin de partie.

## 🛠️ Stack Technique

* **Langage :** C (Standard C11/C17)
* **IDE :** Visual Studio 2022
* **Compilateur :** MSVC (Microsoft Visual C++)
* **Plateforme :** Windows

## ⚙️ Compilation et Exécution

1.  **Prérequis :** Avoir installé [Visual Studio 2022](https://visualstudio.microsoft.com/fr/) avec la charge de travail "Développement Desktop en C++".
2.  **Ouvrir le projet :** Double-cliquez sur le fichier sln.
3.  **Générer la solution :** `Ctrl + Maj + B`.
4.  **Lancer le jeu :** `F5` (ou bouton "Démarrer" dans VS).
